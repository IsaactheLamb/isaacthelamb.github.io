# IsaacMail privacy policy

Last updated 12 October 2026.

IsaacMail is a private app used only by its owner, Isaac Lam. It connects only to his own Gmail account.

**What it uses.** With his permission, IsaacMail reads his Gmail so he can review it. It archives, labels, marks read, bins, sends and unsubscribes only when he asks.

**Where data is kept.** Mail and sign-in details stay on Isaac's own devices. Nothing is sent anywhere except Google's own Gmail service.

**Sharing.** IsaacMail does not share, sell or transfer any data. It does not use Gmail data for advertising or to train AI.

**Google API data.** IsaacMail's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
